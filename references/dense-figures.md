# 在出版尺寸内组织密集证据

## 先看标记之间还剩多少纸面

把有代表性的一小段放到最终字号和栏宽下，包含紧邻的对象、弱变化与真实组界。观察相邻标记边缘之间的净空。点很小却彼此隔得很远，眼睛就要逐个跳读；格子铺得很大，每多用一截纸只是在延长同一种颜色。沿重复最多的方向收紧，直到同组可以连续扫读，仍能认清相邻对象与标签。给组界、换读数和需要看清转折的地方留出停顿。空间或时间坐标本身有意义时，保住数据位置，改从标记、注释距离和面板占幅入手。

纸面预算可以很简单。若每行中心距约 3 mm，24 行约占 72 mm，再加块间隙、标题、标签和图例。中心距由真实标记和字体试排得出。共用一行的点、文字与侧轨一起试，最难读的一处决定还能压多少。长术语在最终设备上测字宽，可换行或重新分配标签列。若只能把字缩小才让页面显得充实，应回头看哪些证据本可以靠得更近、共用一处参照。

## 选择了矩阵或逐项对照时

- **顺序也是信息。** 保留有意义的时间、配对、层级或既有排序，用稳定标识连接观测与注释。转置、分块或重排后，让各层沿最终绘制顺序对应。试着在组界附近横读一行，行名、格子、侧面读数应指向同一对象；读一列也应能定位对应的样本。行数相等并不能排除错位。
- **让细小单元连成可读的纹理。** 组内相邻单元可以自然衔接，组界在读法改变处显现。密格逐格描边若在缩印后浮成网纹，先减轻描边。整体偏高的一组里，反向的一列、局部缺测和弱渐变仍应读得出来。让真实变化决定纹理，避免插值制造连续性。
- **辅助层跟随它解释的对象。** 一项属性可沿对应的行、列或组紧靠主体，各层按各自的信息量给宽度。逐项值与行中心对齐，整组的值标清覆盖范围。侧面只有一个读数时，一条窄轨就能承载；侧面本身有重要内部变化时，给它足以分辨变化的空间。
- **多种量各自能读。** 对应位置可以共用，独立量纲仍有明确名称、范围、单位与适用对象。两套渐变相像时留意读者是否会把同一颜色当成同一数值。读者需要精确查值的地方可就近放数字，扫读连续形态的区域则要保护颜色的连续阅读。

## 推敲已经选用的标记

| 图中已有的元素 | 在成图上找什么 |
|---|---|
| 点与窄柱 | 查最靠近的一对。描边会改变小点的可见面积，间距会影响相邻柱和数字的归属。大小表示面积时，图例与实物用同一映射。极小标记如需放大解释，应能辨出示意与实际比例。 |
| 群体、轮廓与局部窗口 | 轮廓覆盖实际区域，稀疏尾部、离散部分和真实重叠仍可见。定位线条清楚且从属于数据。放大窗让人知道看的是哪里，缩放后锚点仍指向原处。 |
| 连线、箭头与流带 | 顺着一条线能查到两端，方向明确，穿过密集区时能与背景分开。按宽度读数量的流带须保住比例，进出端的空间应足够辨认连接。曲直和走向取决于真实关系与交叉情况。 |
| 空间坐标、影像与形态 | 可比较的视图保住物理标定与方向，局部放大带有相应的定位与比例尺。颜色、遮挡与光照要让读者辨出结构和观测层。细小结构在最终导出后仍应连续可见。 |

## 看收紧之后多读到了什么

在同样的物理尺寸下看改前改后的一小段。视线能直接从对象移到相关读数，能看到一个先前被空白或粗描边打断的连续变化，才说明有效密度提高。再看全页，检验这些局部是否仍能组成清楚的整体。若色彩只在图例里鲜亮、独立面板被硬拉成同宽，或相邻行看似对齐却指向不同对象，优先修正承载这项关系的标记与空间。
