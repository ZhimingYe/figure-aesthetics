# 视觉风格：颜色、文字与诊断

以下是可调整的风格与工程起点。以实际尺寸的可读性、数据语义和用户意图作判断，不把参数范围当作审美合格线。

## 语义色，而不是装饰色

先列条件、类别、方向、连续量、中性与强调的映射。语义相同跨图同色；在同一解释范围内避免同色异义。已确认色表优先。

新设计默认纯白底、纯黑字、alpha=1 的实心标记；透明度只在遮挡/叠层有实际用途时使用。避免粉彩、透明与米色底叠成灰雾，也避免所有对象都用荧光强调。

- 有明确主角：一个强锚色 + 安静的辅助色或同色相明度阶梯。
- 平等类别：相近视觉重量，不能用一强多弱暗示不存在的重要性。
- 相邻易混类别优先拉开色相，同族可拉明度。色差数值不能保证真实密度下可辨；必要时结合分组、位置或直接标注。
- 在实际点尺寸与密度、30% 缩略、灰度及色觉缺陷模拟下检查；必要时增加形状/直接标签，不只依靠颜色。
- 对比弱先检查数据分布与色标范围，不为了“更明显”改统计口径。

连续量用连续色标；有意义的零点与双向变化适合以零为中心的发散色标，默认白色中点。单向有序量通常用顺序色标，具体选择取决于量的含义。范围按数据与跨面板可比性设定，不机械套 ±2；明确饱和/裁剪。精确读数保留数字、单位；Low/High 仅用于定性读法并在图注说明范围。色条紧凑但可辨，长度服务于读数精度与布局。

## 字体与标注

默认全图一个正文字号，用字重、位置、留白分层。例外为面板字母、上下标，以及层内统一的示意图内部标签。

| 场景 | 正文建议 | 使用较小字号时 |
|---|---|---|
| A4 整页 | 7.5–8 pt | 通常不低于 7 pt |
| 单栏 | 7–7.5 pt | 6.5 pt 须说明可读性取舍 |
| 250–270 mm 宽画布 | 8.5–10 pt | 按最终显示尺寸检查 |
| atlas / 极密全景 | 根据输出媒介单独预算 | 全景结构可概览，需精读的标签仍须清晰 |

标题通常同正文大小、加粗；面板字母默认大写 A/B/C，位于 gutter，不压图。服从期刊既定编号与跨页规则。示意图内部文字可小 0.5–1 pt，通常仍至少 7 pt。

图面写读者理解的对象和量，不堆内部变量、阈值表达式、方法段或自造缩写。必要的标准术语、单位、数值刻度保留，算法/阈值/重复层级放图注。标签不能把不确定的计算分数改名成已证实的生物学功能。

优先直接标注，细黑引线指向对象内部；可用对象色作标签，但须可读。保持必要色标和大小钥匙。避免大标题、巨型数字、重色胶囊、冗余外框和解释段落。

## 落地参数与测量

- 行距 1.15–1.3 × 字号；热图行 pitch 至少约 0.95 × 字号，旋转标签约 1.0–1.1；点图行 pitch 1.2–1.35。
- 轴线 0.25–0.35 pt；标记 stroke 0.25–0.4 pt；字母到图约 1.5–2 mm。注意 pt 与 mm 换算。
- 字体默认 Arial/Helvetica 或兼容字体；替换需记录，检查 Unicode 和上下标字形。不要把文字轮廓化来掩盖字体问题。
- 在最终字体与输出设备上测文字；默认设备度量不能保证最终 PDF 无压字。按词平衡换行，长标签三行时先检查列宽。

## 把反馈转成动作

| 反馈 | 首查 | 调整方向 |
|---|---|---|
| 丑、缺高级感 | 结构与编码是否仍是被否的那套 | 重新组织信息关系、视觉权重与读取路径，不套固定图型 |
| 海报感 | 大标题、外框、底色、说明段 | 压缩层级，说明进图注 |
| 阴沉、土气 | 低亮度、透明灰雾 | 白底、提亮、实色，保留语义 |
| 太激进 | 到处强强调 | 建主次；平等类别仍保持平等 |
| 看不出区别 | 数据范围、相邻类别、密度 | 修色标映射或增加位置/标签通道 |
| 和谐吗 | 面板比例、对齐、被拉长的图 | 修几何和面积分配 |
| 太愣 | 粗块箭头、折角 | 细长、轻弯、渐细；不改变方向含义 |
| 越改越没有 | 功能细节是否被当装饰删掉 | 对照批准版恢复编码与结构线 |
