# 修改、视觉验收与版本交付

## 修改已有成稿

确认起点文件及生成来源。保留用户明确批准的版本作为基线，另存新版，不覆盖历史；不能把“先看看”自行记为定稿。用户要求的多个改动可以同版完成，记录清楚。开放重设计允许探索不同结构，局部修订保持非目标内容稳定。

从源脚本或可编辑文件修改，保持本次范围之外的内容稳定。用可复现的源码、参数和改动摘要保留来源，沿用已有版本机制；小修无需建立额外的归档体系。

与起点以相同尺度比较，重点检查修改对象及可能联动的区域。重构可改变组织方式，重新评估全图；被否定的方向需要修正其根本问题，不能只换颜色后重新提交。

## 导出选择

从 R 源稿出图，默认使用 ggplot2 和 cairo_pdf。按 [R 制图与拼版](r-production.md) 选择矩阵、组合图及必要的 PDF 拼版方法。

默认 PDF：显式白底、正确物理尺寸、文字可选择且字体嵌入；密集点层/矩阵体需栅格化时按落地尺寸至少 600 dpi，标签与必要结构线保留矢量。兼顾文件体积和编辑性能，不为压缩损失可读性。用户要求 SVG/PNG 或其他背景时服从要求。

检查实际所需工具；缺某个命令时采用等价检查，不要求无关软件齐全。字体或导出设备变更要说明并重新检视。无法验证的项标未验证，不声称通过。

## 三尺度观看：必须看交付文件本身

导出后重新打开或渲染最终文件；中间 PNG 不能替代最终 PDF。

| 尺度 | 检查 |
|---|---|
| 全页缩到 25–40% | 主角、阅读顺序、整体比例、色彩主次、白洞 |
| 最终阅读尺寸 | 字体、对齐、标签、图例、面板字母、内容完整性 |
| 局部高分辨率（约 300–900 dpi） | 每条引线端点、文字压图、边缘切割、描边与点密度 |

逐页检查，不抽样。先修可修缺陷再重出，至少重新检查修改区域与整页。高 dpi 本身不等于视觉检查，必须实际查看渲染图。

## 工程检查与适用边界

选择与输出格式和本次改动相关的检查。新建完整成稿需要验证整体；局部修订重点验证修改区域和潜在联动，不必重跑无关分析或重复已成立的验证。有新变化、失败或未解决疑点时再扩大检查。

| 项目 | 方法示例 | 判定 |
|---|---|---|
| 页数、尺寸 | pdfinfo 或 PDF 库 | 与约定一致 |
| 字体与文本 | pdffonts、pdftotext 或等价工具 | 字体嵌入，无意外 Type 3；文字可提取且视觉正确 |
| 栅格分辨率 | pdfimages -list 或图像对象检查 | 按落地大小满足约定 |
| 边距、裁剪 | 内容 bbox 与页面坐标 + 目视 | 默认内容距页边至少 2 mm，无丢失 |
| 标签大小与重叠 | 源字号 + 最终设备度量 + 目视 | 符合预算；不能只拿文本 bbox 高度当字号 |
| 语义一致 | 图例/颜色/输入/图注逐项核对 | 映射完整、统计与单位一致 |
| 局部修改回归 | 同渲染器同设置，PDF 转 300 dpi，区域差分 | 非目标区无非预期改变 |

注意：显式白色背景可能使通用 ink bbox 覆盖整页，量边距需排除背景对象并结合目视。文本可提取不保证全部标签正确，需检查缺字与上下标。

在完全相同渲染环境下，局部修改的非目标区域以 0 像素差异为理想判据；可用 ImageMagick `compare -metric AE` 或等价库检查。若字体/渲染器变化引入抗锯齿差异，先查原因和几何，不伪报 0 px，也不无限追逐无关栅格噪声。自动布局导致非目标面板移动时固定布局和尺寸，必要时用占位对象加 inset。

## 交付说明

交付成图与当期图注；用户明确不要图注时注明未包含。给出唯一、明确的当前产物链接，简短说明改动及实际采用的画布、字号等关键默认值或例外，有未完成验证则如实说明。保留生成源码、参数及修改摘要，沿用已有归档方式。用户要求方案比较时提供有实质区别的候选。

无法完成的图可保存标为草稿/未通过的诊断输出，说明原因，不包装成合格稿。数据无效时不能为“必须出图”捏造产物。没有实际产物就直接说明缺什么及下一步。
