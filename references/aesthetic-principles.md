# 成品的审美判据

评审时指出读者在哪里失去了一项比较。用实际成图分辨原因，再选择对应层面的修改。

| 看到的现象 | 怎么定位问题 |
|---|---|
| 图很满，内容却单薄 | 沿一层证据读到下一层，看是否获得新的关系。反复陈列同一读数会占满页面，删到只剩摘要又会让真实差异消失。 |
| 图很大，信息仍然稀 | 看同组相邻标记的边缘，以及视线从对象到相关读数的距离。格子过大、点柱间隔过宽、窄轨远离主体，都让纸面在重复同一信息。真正提示换组或隔开独立证据的空白值得保留。 |
| 图例鲜亮，数据却灰 | 在最小标记与最密集的相邻色上看。可能是亮度太近、透明叠层发灰、描边吞掉了实色，也可能是留给数据的有效面积太小。 |
| 色彩丰富，含义却乱 | 沿同一对象跨视图追一次。换面板就换色、两种不同的量看起来共用一把尺、辅助底色比数据更醒目，都值得修正。 |
| 局部生硬或粗糙 | 在所指对象旁读一次色标、引线或边界。色标若压过数据里的变化，检查比例和位置；引线若横穿近邻，检查走向和终点；对齐若暗示错误的对象关系，重排数据区。 |
| 像海报 | 遮住标题和说明，看数据自身能否组织阅读。若第一眼只看到横幅、巨型数字或等大卡片，给主要证据连续空间，让短标签帮助定位，让图注承担长解释。 |

比较改稿时，把两份成品按相同的毫米比例查看。在原来难读的位置，读者现在能否更近地找到参照、分清相邻对象或读到过去被掩盖的变化？缩看全页，再看这些局部是否形成清楚而鲜明的整体。这样也能识别哪些地方已经画好，值得保留。
