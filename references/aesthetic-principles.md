# 成品的审美判据

按实际成图判断，不接受“看起来高级”作为自行改变规范的理由。下面的失败迹象用于定位问题，不是固定的图型推荐。

| 品质 | 成图应呈现什么 | 需要修正的迹象 |
|---|---|---|
| 复杂度 | 同一对象可在整体、组成与局部证据之间查回。每层都让读者多辨认出一项真实关系。 | 各层只是同一数值的反复陈列；或只剩汇总，读者看不到支撑它的差异。 |
| 色彩鲜艳丰富度 | 分类实色在实际标记大小下清楚，连续变化有可辨的层次；缩小看，数据本身形成鲜明的色群。 | 颜色在图例里醒目，在数据里却稀散；灰底、透明或过细的有色标记把真实差异冲淡。 |
| 高级感 | 主图有足够面积，同类样式统一，比例准确，标签与对象对应精密，细线与实色清晰。 | 辅助示意压过数据；标题、标签大小各异；背景灰雾；拉长矩阵填空；轴线、轮廓、图例各用一套样式。 |
| 高信息密度 | 同一阅读区域内能比较多项有效证据；共享顺序和参照，保留异质性与局部变化。 | 大片留白配几个汇总值；重复图层堆数目；把密度等同于小字；删基因、term 或色标来变“干净”。 |
| 学术创意 | 层次、注释、局部与跨视角的对应让真实关系更易发现，复杂内容有稳定读法。 | 只换颜色；套用默认绘图库版式；无依据增加网络、环形、连线或注释轨道；各面板互不关联。 |
| 非海报感 | 数据形状和关系承担表现力，标题同正文大小，短标签定位，解释在图注。 | 横幅、大字、巨型数字、圆角卡片、装饰底色、阴影、粗箭头、整段说明占据视觉中心。 |
| 精密感 | 分组边界、标签锚点、引线、注释条、色标与图形对齐，外缘与间隙统一。 | 引线断开或指错；小面板悬在行顶；图例远离对象；计算错误形成白洞；裁切、压字。 |

## 用成图走一遍阅读路径

以实际出版尺寸读一个典型对象，再读一个例外。检查两次阅读中视线在哪儿中断、哪种颜色需要重新查义、哪个对应关系需要靠数位置才能辨认。能通过邻接、共同顺序或直接标注解决的，在原处解决。改版时将两份最终文件按相同的毫米比例并排看，避免预览器分别把两页撑满窗口。先比较同一小段内字、标记、净空与组界的相对变化，再检查哪一项过去要跨区搜索或心算的关系现在能直接读出。随后缩小看整页，检查刚才读过的细节是否共同显出总体模式。两种尺度都成立，才算取得了有效的信息密度。

## 把反馈落实为修正

- “阴沉、土气”：检查颜色亮度和透明灰雾，恢复白底与明亮实色；不能只把饱和度再降一遍。
- “太激进”：减少无意义的强强调，使主次明确；平等类别仍保留相当权重。
- “看不出区别”：先查数据范围、映射和实际密度中的类别可辨性；不换统计口径制造差异。
- “不和谐”：检查主辅面积、宽高比、外缘与间距；不能只换配色。
- “太愣”：检查粗块箭头和生硬转折，改为轻细、方向清楚的连接；保留真实语义。
- “越改越没有”：对照起点，检查是否删掉了有效覆盖层、轮廓、引线、色标或局部证据，恢复其作用。

先修缺陷所在的层级。已成立的结构不为形式翻新而重做，被否定的结构也不能换一套颜色后再次提交。对照最终尺寸及修改前版本，确认修正没有牺牲别处的可读性。
