# R、ggplot2 与最终纸面

新作和重绘首选 R。沿用已有的 ggplot2 图层、比较顺序和语义色表，便于修改一处后从同一源稿复现全页。单个复合图内可组合 ggplot2、ComplexHeatmap 和 grid。期刊或用户给出最终毫米尺寸时，直接按该尺寸开启 PDF 设备，按落地大小定字号和线宽。

## 在绘图对象中控制密度

- **文字。** theme() 的 element_text(size=8) 用 pt，geom_text() 需要相应版本支持的 size.unit="pt"，旧版本按其单位换算。单设 base_size 不会消除主题对 axis.text、图例、分面标题的相对缩放。给这些元素显式设同一正文字号，检查最终 PDF。数学符号、斜体基因名、上下标及负号用最终字体试排。
- **矩阵。** 用具有给定水平的因子锁定分组顺序，按 ID 连接注释后显式核对顺序。规则格点可用 geom_raster(interpolate=FALSE)，单元少或宽度、间隙可变时用无描边 geom_tile()。ComplexHeatmap 的树、split、组内排序和注释共用同一索引。输入已有聚类时显式保留该排序，避免第二次聚类悄悄改变顺序。分块后标签、侧图和树叶都要对应最终绘制顺序。
- **颜色与缺失。** 用具名向量记录类别到颜色的映射；跨页子集中也保持键值稳定。双向量在零处设白色，limits、超限处理和 na.value 分别明确。超界值需要饱和时显式设置压到端点，并在图注披露。默认把越界值变成 NA 会让最强信号在图上看成缺测。
- **比率与面积。** 若零应对应零面积，按量与圆面积映射，检查零点与图例中的示范点。ggplot2 的点形、size、stroke 会共同改变落地外径。描边用独立图层时，核对带环与无环点的主体面积一致。小点聚在一起时先改描边或图层绘制顺序。
- **跨面板对齐。** patchwork 适合组装共享版面的绘图对象。长术语、纵轴数字和侧置图例会吃掉 panel 内部宽度。用 ggplotGrob()/gtable 检查 panel 区间。必要时用 grid 的 mm 单位统一数据区域、标签栏与窄轨长度。共享行轴的小图还要共用 limits、expand、行距和块缝。合并图例前确认变量、单位、范围及图例键全部相同。
- **混合导出。** 用 ggsave() 指定 width、height、units="mm"、device=cairo_pdf、bg="white"。大量散点或密集矩阵可单独栅格化，按最终印刷尺寸给足约 600 dpi；小规模矩阵可保留无描边矢量格。文字、引线、图例和比例尺保留矢量。不要把整页截图嵌进 PDF。
- **已有成品拼版。** 优先在 R 中拼可编辑的绘图对象。输入只有独立 PDF，且必须保留其文字、路径、裁剪框或物理比例时，可用 Python 的 PDF 工具做必要拼版。用原页的矢量内容放置，按目标栏宽复核文字落地尺寸。图内数据仍从 R 源稿绘制。
