# 图注、统计与证据边界

图面展示对象与编码；图注解释读图所必需而无法在图面容纳的定义。按实际适用项检查，不为不涉及统计的示意图补造统计。

## 图注清单

1. 对象、条件和样本是什么。
2. 颜色/大小/线型的含义，色标范围和单位。
3. 检验、校正方法、重复层级、n、误差线/置信区间定义。
4. 显示范围裁剪、子抽样、缺失处理、变换或标准化。
5. 新派生量如何定义，单位和区间表示什么。
6. 比例尺校准及不可消除的数据局限。

阈值和算法通常进图注；图中必要的单位、数字和标准名称保留。名称一致：同一组不要混用 Control/Baseline/Normal；两套 Low/High 若定义不同须区分。

## 统计纪律

- 区分原始 P、校正后 P/q 和校正方法；不把名义显著称为校正后显著。按分析方案提供必要数值与方法；上游未提供的值不能编造或为排版擅自重算。
- 需要显著性分档时明确阈值，如 q<0.05、仅名义 P<0.05、n.s.，符号不可混用。服从实际分析方案，不强加 0.05 阈值。
- n 对应推断的独立实验单位；细胞、bin、切片、技术重复不能冒充生物学重复。样本到个体关系未知时按已知层级描述并披露。
- 误差线真实对应 SD、SEM 或 CI，不混称；n 很小时显示原始点并说明，例如 n=2 的 mean±SD，不能假造精确性。
- 相关、共定位不写驱动/促进/调控；未经检验的流向不支撑速度或组间差异。
- 命名与声称不得超出证据。生物学解释可以是假设，但必须标明。

## 图面缺陷与数据局限分开处理

压字、切边、断引线、比例失衡、缺色标：能改图解决就修，不用 caveat 代替修复。

样本量不足、单位未校准、统计口径偏倚、复现未验证：必须披露，换图形也不能消除。已知方法在必要验证上失败时，不把结果当有效证据交付；保存诊断产物并报告原因，重新分析或换方法需依任务授权。

误差须超界时显示真实范围或清楚标出裁剪；不能为了“不穿轴”伪改区间。抽样说明总体与显示数量及方法，不知道的量明确未知。图注数字必须与图上值一致。
